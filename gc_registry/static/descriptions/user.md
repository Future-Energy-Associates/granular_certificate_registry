Management of individuals affiliated with an Organisation that can manage zero or
more Accounts. Users are assigned roles that govern their access privileges across
the registry. Available roles, in descending order of privilege, are: Admin,
Production User, Trading User, Audit User, and Storage Validator.

User creation and role changes require Admin privileges. Users can update their
own profile information, while Admins can update any user. A test account
provisioning endpoint is available for internal use, which creates a new user
and account, links them to a central test account, and configures bidirectional
whitelist permissions for transfer operations.
